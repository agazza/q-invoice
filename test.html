ℹ️ Come funziona

  • Carica un file XML di fattura elettronica italiana (FatturaPA)
  • L'app estrae automaticamente IBAN, importo, beneficiario e causale
  • Genera un QR code EPC compatibile con le app di home banking
  • Scansiona il QR code con l'app della tua banca per pagare
